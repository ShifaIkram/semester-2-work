# Semester Work 3 – Programming Fundamentals

This repository contains my **Semester Work 3** for the course **Programming Fundamentals & Data Science**.  
It includes lab tasks completed in **Python** based on the topic of **Functions in Python**.

## 📘 Course Information
- **University:** University of Engineering and Technology, Lahore  
- **Department:** Computer Engineering  
- **Course Code:** CMPE-112L  
- **Semester:** 2nd Semester  
- **Session:** 2025–2026  

## 🧠 Lab Title
**Functions in Python**

## 🎯 Objectives
The purpose of this lab was to understand:

- User-defined functions in Python  
- Defining and calling functions  
- Return statements in functions  
- Different types of function arguments  
- Lambda (anonymous) functions  
- Docstrings in Python  

## 📝 Tasks Included

1. Calculate **Permutation and Combination** of `n` and `r` using user-defined functions  
2. Find the larger of two numbers using a **lambda function**, then print its table to a specified range using a UDF  
3. Convert a string to uppercase using a **lambda function** and reverse it using a UDF named `invert`  
4. Convert:

   - Fahrenheit to Celsius  
   - Celsius to Fahrenheit  

5. Calculate **Semester GPA** using user-defined functions based on:

   - Grade points  
   - Credit hours  
   - Total subjects studied
