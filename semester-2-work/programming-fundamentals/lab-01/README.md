# 🧪 Lab 01 – Programming Fundamentals (Python)

## 📘 Overview

This lab focuses on the **fundamental concepts of Python programming**, including input/output operations, data types, string handling, and conditional statements.

It is part of the course:

**Fundamentals of Programming & Data Science (CMPE-112L)**
University of Engineering and Technology, Lahore

---

## 🎯 Objectives

By completing this lab, the following concepts are covered:

* Understanding Python **input() and print() functions**
* Learning different **data types** in Python
* Working with **strings and formatting**
* Applying **conditional statements (if, else, elif)**
* Developing basic **problem-solving skills**

---

## 📚 Topics Covered

### 🔹 Input & Output

* `print()` function and its parameters
* `input()` function for user input

### 🔹 Escape Sequences

* `\n`, `\t`, `\\`, `\"`, `\'`

### 🔹 String Formatting

* `%` operator
* `format()` method
* f-strings

### 🔹 Data Types

* Numeric (int, float, complex)
* Boolean (True/False)
* String
* List, Tuple, Set, Dictionary (overview)

### 🔹 String Operations

* Indexing and slicing
* Built-in methods like:

  * `upper()`, `lower()`, `replace()`
  * `count()`, `find()`, `endswith()`

### 🔹 Conditional Statements

* `if` statement
* `if-else`
* `elif`
* Nested conditions

## 🧩 Lab Tasks

The following tasks were implemented in Python:

1. Convert bytes into **Megabytes and Gigabytes**
2. Calculate **ECAT aggregate** using:

   * ECAT (33%)
   * Intermediate (50%)
   * Matric (17%)
3. Check whether a number is a **palindrome**
4. Calculate:

   * Distance between two points
   * Determine their **quadrants**
5. Solve a **quadratic equation**:

   * Determine nature of roots using discriminant
   * Calculate roots using quadratic formula
