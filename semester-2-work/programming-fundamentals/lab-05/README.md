Semester Work 2 – Programming Fundamentals

This repository contains my Semester Work 2 for the course Programming Fundamentals & Data Science.
It includes lab tasks completed in Python based on the topic of Recursion.

📘 Course Information
University: University of Engineering and Technology, Lahore
Department: Computer Engineering
Course Code: CMPE-112L
Semester: 2nd Semester
Session: 2025–2026

🧠 Lab Title
Recursion in Python

🎯 Objectives
The purpose of this lab was to understand:

Concept of recursion in Python
Base case and recursive case
Working of recursive functions
Call stack and execution flow
Types of recursion (Direct, Indirect, Tail, Head)
Problem solving using recursion

📝 Tasks Included
Write a Python program to calculate Permutation and Combination (nPr and nCr) using recursion
Print the first 20 terms of the Fibonacci sequence using recursion
Generate a list of 10 random numbers and calculate their sum using recursion
Write a program to calculate the power of a number using recursion
Take a string input and reverse it using recursion
Create a program that extracts only string values from a mixed list using recursion

Python 3
