**List and Tuple**

## 🎯 Objectives
The purpose of this lab was to understand:

- Lists in Python  
- Tuple data structure in Python  
- Indexing and slicing  
- Built-in list methods  
- Tuple methods and operations  
- Nested lists and matrices  
- List comprehension  

## 📝 Tasks Included

1. Take a list as input and remove duplicate elements by creating a new list  
2. Find the **second smallest element** in a list  
3. Write a **user-defined function** that takes two tuples and returns their intersection  
4. Take 3 rows as input, display a **3×3 matrix**, calculate its transpose, and display it
